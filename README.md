# たびクエスト

家族の旅を、日本地図の上に一つずつ積み上げていくための小さなアプリです。

旅行に行くたびに「旅行その2」「旅行その3」と足していけます。
**家族に送るURLは、最初の1本のままずっと変わりません。**

もとは「佐渡クエスト」という佐渡島だけのアプリでした。
佐渡の記録は「旅行その1」としてそのまま残っています。

---

## 使うのは、この2つのURLだけ

**お父さん用（投稿する画面）**

```
https://kentaroonakamaido-bit.github.io/sado-quest/admin.html
```

**ログインも、パスワードも、合言葉も要りません。開いたらすぐ投稿できます。**

iPhoneのSafariで開いて、**ホーム画面に追加**しておくとアプリのように一発で開けます。
（共有ボタン → 「ホーム画面に追加」）

> このURLを持っている人は誰でも投稿・修正・削除ができます。
> 家族用と割り切った作りなので、**人には渡さないでください。**

**家族用（見る画面）**

```
https://kentaroonakamaido-bit.github.io/sado-quest/index.html?t=（合言葉）
```

`（合言葉）` の部分は、投稿画面を開くと自動で表示されます。
**「コピーする」ボタンを押して、そのままLINEに貼って送ってください。**

このURLは**一度送れば、それきりです。**
旅行が増えても、送り直す必要はありません。

## 旅行に行くたびにやること

### 出発前（30秒）

1. 管理画面を開く
2. 一番上の **「＋ 新しい旅行を始める」** を開く
3. 旅行の名前（例：「北海道クエスト」）と、地域名（例：「北海道・富良野」）、出発日を入れる
4. 「この旅行を始める」を押す

これで新しい旅行が「冒険中」になります。
前の旅行は自動で「終わり」になるので、切り替え忘れの心配はありません。

家族側の画面では、この瞬間から新しい旅行が日本地図のピンとして増えます。

### 旅行中

写真を選ぶ → 現在地を取得する → ひとことを書く → 投稿する。これだけです。

- **場所名とひとことは、書かなくても投稿できます。** 急いでいるときは写真と場所だけでOK
- **電波が悪くて失敗しても、入力した内容は消えません。** 電波の届く場所でもう一度ボタンを押してください
- **同じ写真が二重に投稿されることはありません**（送信中はボタンが押せなくなります）
- 現在地が取れないときは、緯度・経度を手で入れることもできます

### 帰ってきたら

管理画面の **「この旅行を「終わり」にする」** を押すだけです。
押さなくても壊れませんが、押すと家族側の「冒険中！」の表示が消えて落ち着きます。

過去の旅行に写真を足したくなったら、上の「旅行を選ぶ」で切り替えれば、
終わった旅行にもあとから投稿できます。

## 家族側の見え方

**1枚目：日本地図**

- 行った旅行が、金色の番号つきピンとして日本地図に並びます
- いま旅行中のものだけ、赤く脈打って光ります
- 地図の下に、旅行の一覧（表紙の写真・期間・写真の枚数）が並びます
- ピンか一覧を押すと、その旅行の詳細地図に入ります

**2枚目：旅行ごとの詳細地図**

- その旅行で回った場所に、行った順番の番号つきピンが並びます
- ピンとピンは線でつながっていて、回った道すじが分かります
- 一番新しいピンは赤く大きく光ります（「いまここ」）
- 地図の下に写真が大きく出て、さらに下に「冒険ログ」として全部の写真が並びます
- 「← ぜんぶの旅を見る（日本地図）」で1枚目に戻れます

いま冒険中の旅行があるときは、URLを開くといきなりその旅行の地図が開きます。
祖父母が「どれを押せばいいの？」と迷わないためです。

祖父母でも使えるよう、文字は大きめ、ボタンは押しやすい大きさにしてあります。
**ログインも会員登録も要りません。URLを開くだけです。**

## 見せるのをやめたいとき

GitHub の `Settings` → `Pages` → `Branch` を `None` にして `Save` を押してください。
URLを知っている人でも開けなくなります。写真やデータは消えません。

また見せたくなったら、同じ場所で `main` に戻せば復活します。

---

## Supabaseが「一時停止」になったときは

無料プランのSupabaseは、1週間ほど使わないと自動で一時停止します。
停止中は家族用URLが「読み込みに失敗しました」になります。

直し方は簡単です。

1. https://supabase.com/dashboard を開いてログインする
2. プロジェクトに **Restore project**（プロジェクトを復元）のボタンが出ているので押す
3. 数分待つと元どおりになります

データは消えていません。

## 仕組み（技術メモ）

| 役割 | 使っているもの |
|---|---|
| 画面の配信 | GitHub Pages（このリポジトリのルート直下） |
| 投稿データ | Supabase Database（PostgreSQL） |
| 写真 | Supabase Storage（photos バケット） |
| ログイン | ありません |
| 地図 | Leaflet ＋ OpenStreetMap（無料・APIキー不要） |

ビルド作業はありません。HTMLファイルを置いているだけです。

### データの持ち方

```
マップ（maps）        ← 家族に配る合言葉は、ここが持っています。ずっと1つ
 └ 旅行（trips）      ← 旅行に行くたびに増えます。佐渡が1件目
    └ 投稿（posts）   ← 写真1枚＋位置＋ひとこと
```

合言葉がマップ側にあるので、**旅行を何件増やしてもURLは変わりません。**
これが「送ったURLがずっと使える」理由です。

### ファイル

```
index.html            家族向けの地図画面（公開されているのはこちら）
admin.html            お父さん用の投稿・管理画面
config.js             接続先の設定（公開してよい値のみ）
app/                  同じ内容の作業用コピー
supabase/schema.sql   データベースの土台
supabase/setup.sql    ★これ1本だけ流せば準備完了（日本地図化＋ログイン不要化）
docs/requirements.md  要件定義書
```

> **注意：** GitHub Pages が配信しているのは**リポジトリのルート直下**の
> `index.html` / `admin.html` です。`app/` の中を直しただけでは反映されません。
> 直したら必ずルートにも同じものを置いてください。

### 安全について（家族用と割り切っています）

**投稿画面には鍵をかけていません。** `admin.html` のURLを知っている人なら
誰でも投稿・修正・削除ができます。毎回パスワードを打つ手間をなくすための割り切りです。

そのうえで、次のことはしています。

- **家族が見る画面（`index.html`）には合言葉が要ります。** `?t=...` の部分です
- 家族は「合言葉を渡すと結果を返す専用の関数」経由でだけ閲覧できます。合言葉が違えば、空っぽが返るだけです
- 写真は投稿前にブラウザ内で縮小され、その過程で**撮影場所などのEXIF情報は消えます**
- 検索エンジンには載りません（noindex）
- 画面に住所や家族の本名は出しません

もし後から投稿画面にも鍵をかけたくなったら、`supabase/setup.sql` の
第2部にある `create policy` を全部 `drop policy` に読み替えて実行すれば閉じられます。

### 準備・作り直しの手順

Supabase の SQL Editor に貼って「Run」を押すだけです。何度実行しても壊れません。

1. `supabase/schema.sql` （まだ一度も作っていない場合だけ）
2. `supabase/setup.sql` ★

**Edge Function の用意は要りません。** 写真は画面から直接 Storage に送っています。

`setup.sql` を実行すると、いちばん下に家族に送るURLがそのまま表示されます。
